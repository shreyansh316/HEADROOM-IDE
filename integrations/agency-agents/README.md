Selected specialized skills:
1. `code-reviewer`: Strict code review checklists, automated security smells, git hygiene.
2. `git-workflow-master`: Branch naming conventions, atomic commit hygiene, rebasing safety.
3. `test-automation-engineer`: Unit test coverage generation, edge-case coverage patterns.
4. `evidence-collector`: Verification log collection, diff inspection, quality gate confirmation.
5. `technical-writer`: Architectural docs, user-facing changelog, delivery reporting.
